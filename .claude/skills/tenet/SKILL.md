# /tenet - Instant JSONL Download

Speichere den aktuellen Chat als JSONL-Datei zum Download - blind, ohne Worte, in einem Zug.

## Usage

Simply type `/tenet` in Claude Code chat to download the current conversation as JSONL.

The command:
- Finds the current cloud session JSONL
- Copies it to the download folder with a Git-branch-based filename
- Makes it ready for instant download

## Output

Downloads a file like: `conversation_2026-09-02_14-45-10.jsonl`

The file is automatically ready in your download folder.
